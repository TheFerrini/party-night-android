## Party Night v2.2.0 — God Mode & Adaptive UI

- Added configurable God Mode with random three-box choices during games, including a wildcard, randomized drink penalties and actions that incur two drinks if rejected.
- Statistics canvas height now follows the active Overview, Games or Players panel.
- Reduced long game prompt typography to prevent overlap and improved translation of dynamic game details.
- Raised the updates dialog above bottom navigation and added safe-area spacing.
- Reduced launcher beer mug artwork so both mugs read clearly in adaptive icon masks.
- Added the 2.2.0 entry to the in-app changelog; previous release history remains available.
